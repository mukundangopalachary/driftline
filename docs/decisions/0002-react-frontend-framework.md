# 0002: React as frontend framework on Vite

- Date: 2026-11-18
- Decided by: owner
- Status: accepted

## Decision

Use React on Vite for the frontend.

## Options considered

React, Vue, Svelte, Solid. React has the largest ecosystem, including table and form libraries suited to a dashboard UI.

## Not decided here

- TypeScript vs plain JS (open)
- Routing, state management, UI component library (open)
